정보 수집 · 핵심노트 작업실

텍스트, 여러 주소, RSS·JSON 피드를 한곳에서 정리해. AI API 없이 작동하는 규칙 기반 추출이라 원문과 출처를 보존하고, 불확실한 내용은 직접 확인해야 해.

1. 자료 넣기여러 줄 / 여러 URL 지원
주소는 한 줄에 하나씩 넣어도 돼. 사이트가 외부 접속을 막거나 로그인해야 하면 자동 수집이 안 될 수 있어.
2. 자동 분류 기준기본값은 자동 분류
칩의 ×로 삭제, 이름을 누르면 이름 변경. ‘자동 분류’는 입력 내용의 단어를 보고 분류해.
3. 참여 방식 태그여러 개 선택 가능
4. 추출 설정
자동으로 뽑는 항목: 제목 후보, 카테고리, 참여 방식, 금액·인원 등 숫자, 날짜·기간, URL. 조건·주의사항의 의미 판단은 AI 없이 완벽히 보장할 수 없어.
